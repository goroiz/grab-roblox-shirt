# Roblox Classic Shirt Template Grabber

Ambil PNG template dari **Classic Shirt / T-Shirt / Pants** (Roblox) pakai Node.js.  
Input bisa berupa **URL catalog** atau **asset ID**. Output: file PNG di folder `output/`.

> **Gunakan untuk personal use**. Jangan reupload/jual ulang karya orang (bisa kena DMCA/banned).

## Cara pakai (cepet)

1. Install Node.js (v16+)
2. Clone repo ini & install dependency:
   ```bash
   npm i
